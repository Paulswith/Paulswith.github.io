  1. Clean build cache
  2. 编译出.archive
  3. xcrun打包为.ipa文件

第三步是和XCode9差异最大的地方, 先记住这里:

脚本化

稍微优化了一下:

  1. 添加xcpretty美化xcodebuild出来的那团东西, 安装请执行gem install xcpretty

使用指南

  • 项目根目录生成package文件夹, 将脚本和ExportOptions.plist放进去.
